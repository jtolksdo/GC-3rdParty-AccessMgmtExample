Prefer not to choose? The chat bubble in the corner connects you without a station.

How this demo works

  1. You pick a station. The page stores it as a Web Messaging custom attribute (location) before the chat starts.
  2. Genesys Cloud routes the chat. A bot asks for your last name, then an Architect inbound message flow transfers the chat to the WX-84 Weather Desk queue. Every agent in the group WX-84 Agents can take it.
  3. The agent answers in Genesys Cloud. The WX-84 console opens in the interaction panel. It signs the agent in with their verified Genesys identity and shows only the stations that agent is cleared for; the others are hidden. If the agent is not cleared for your station, the console says so.
Demo website, not a real service. Weather data from Open-Meteo.com. Chat powered by Genesys Cloud Web Messaging.
