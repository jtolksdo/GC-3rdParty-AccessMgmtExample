WX-84 Flight Weather Desk
How this demo works

Duty meteorologists on call around the clock

Need a weather briefing?
Pick a station and start a chat.

Each station has its own duty meteorologist. Choose where you are flying to, and your chat goes straight to the person in charge of that station.

Prefer not to choose? The chat bubble in the corner connects you to the duty supervisor.

How this demo works

  1. You pick a station. The page stores it as a Web Messaging custom attribute (location) before the chat starts.
  2. Genesys Cloud routes the chat. An Architect inbound message flow reads the attribute and transfers the chat to the station's queue. Without a station, the chat goes to the WX-84 Supervisor queue.
  3. The agent answers in Genesys Cloud. The WX-84 console opens in the interaction panel. It signs the agent in with their verified Genesys identity and shows only the stations that agent is cleared for.
Demo website, not a real service. Weather data from Open-Meteo.com. Chat powered by Genesys Cloud Web Messaging.
